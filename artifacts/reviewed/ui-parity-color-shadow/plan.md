# Capture original color editing and Series Shadow in nine cases

Run the bounded original-UI experiment below before extending the frozen editor or appearance contracts. The smallest useful comparison uses the visible bottom category-axis line, left number-axis grid and bar-series Shadow. Ordinary bar fill/stroke and line-marker color pickers are not present in the inspected matching editor source; do not invent those controls or change family to find substitutes.

This is R3 source research dated 2026-10-17, not a runtime result, implementation task plan, phase approval or parity claim. Only this plan and [source-hashes.json](source-hashes.json) are authored. Publication-relative links are written for the eventual `artifacts/reviewed/ui-parity-color-shadow/` location. The owning specification language is English. Production size caps do not apply to these documentation/data outputs; any later maintained collector/production work must retain the inventory/checker and 400 physical lines/file, 300 logical units/file and 50/function caps.
