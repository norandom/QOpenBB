# Ordinary Cartesian formatting: application contract

The owned source settles formatter inputs and override composition for grouped columns, stacked columns and line. Preserve these callbacks as separate display policies; a single decimal count or a table value formatter cannot reproduce them. AG-owned control behavior and callback invocation still require original-browser evidence. This is source discovery, not design approval or renderer acceptance.

## Date and numeric semantics

`Chart/utils.tsx:59` checks Date instances before fiscal conversion: they become UTC ISO text through seconds, dropping midnight time. The original `AgGridUtils.tsx` datetime pattern requires `YYYY-MM-DD HH:mm:ss` with a space separator; date-only `YYYY-MM-DD` or `M/D/YYYY` uses a separate pattern. ISO strings with a `T` separator are not recognized by these patterns. Only recognized datetime strings at midnight become `YYYY-MM-DD` before period conversion. Recognized date-only and non-midnight datetime strings reach fiscal conversion: `Qn` plus newline plus year for chart types containing `Column`, a space for line/legend/tooltip, or `FY yyyy` for annual; otherwise the input is retained. Date objects and strings can therefore take different paths despite denoting the same day. Source uses calendar quarter/year; it does not prove an issuer-specific fiscal calendar. Preserve these original helper contracts rather than broadening parsing with locale defaults.

`lib/utils/utils.ts:532`, `:581` and `:597` define numeric display. Zero becomes `0`, NaN becomes `N/A`, integer inputs need not acquire decimal padding, fractional values below magnitude one force at least two decimal places, and magnitude formatting uses a strict million threshold with M/B/T suffixes and at most three fractional digits. This is not general fixed-decimal formatting and does not abbreviate thousands to K. Preserve the helper behavior, including boundary rounding and spacing, rather than replacing it with locale defaults. These are display transformations, not observation rescaling.

For detached extraction only, `Chart/utils.tsx:465` selectively calls colDefFormatter for percent/normalizedPercent or titleCase/hoverCard definitions, then strips nonnumeric characters and converts back to Number when the original datum was numeric. `AgGrid.tsx:396` multiplies normalized values by 100; percent retains the input scale. Thus a detached normalizedPercent datum can enter chart data at percentage-point scale without retaining `%`. The extraction does not forward widgetId or the global decimal setting to colDefFormatter. It also does not copy prefix/suffix into its widgetDefs object. Ordinary integrated charts return before this extraction (`Chart/utils.tsx:603`). Integrated AG handling of column formatting remains an invocation question, not a reason to apply detached conversion globally.

## Concrete option precedence

1. Generate axis/series callbacks above; lodash-merge caller chartAxis/chartSeries over them. A caller can replace a formatter. Generate `common.axes`, full `line.series`, and `bar.series` with connectMissingData and marker removed and outside-end labels (`Chart/hooks/useChartOptions.tsx:36`, `:387`).
2. Generate common legend and navigator. Assign `chartOptions.common = options.common` before lodash `merge(options, chartOptions)` (`:397`, `:431`). Saved common settings are replaced at this composition point, not merged underneath their saved counterparts.
3. Saved family branches merge over generated family branches. A saved `bar.series.label.enabled`, `bar.series.tooltip.enabled`, `bar.axes.number` or `bar.title` is retained in the bar namespace; the equivalent line patch belongs under `line`. Retained inactive-family branches must survive state storage. This source does not establish AG's final common-versus-family axis resolution or editor-produced position-specific axis patch paths.
4. Source-owned callbacks must be regenerated from current widget/context inputs, not serialized as function text. The original options event merges state options with event options, removes top-level theme and stores the current model (`Chart/hooks/useChartOptions.tsx:436` onward). That proves the application handler, not which event an AG control emits.
