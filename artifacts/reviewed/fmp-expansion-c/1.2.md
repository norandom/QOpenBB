## Boundary and private evidence

The live and synthetic ledgers are separate SQLite databases. Before the one permitted HTTP GET, an immediate transaction commits the reservation with full synchronous writes. An unresolved reservation blocks every subsequent send across all lanes and process restarts. The controller treats a crash between reservation and finalization as a consumed slot and a halted run. A finalized response records safe status, timestamps, exact body bytes within the 4 MiB capture bound, and a body SHA-256. A bounded or failed read can leave the body unavailable. The per-case and per-lane allowance is enforced with the aggregate 30-send ceiling. A transport failure consumes its reservation. Redirect responses consume one send and are not followed. Authentication and throttling set a durable whole-run stop; entitlement blocks that endpoint across lanes. A qualified independent endpoint may proceed after entitlement denial. Each dependent reservation validates the expected preceding case ID, lane, endpoint and exact provider query within the reservation transaction. For phase progression, the predecessor must retain a complete body and normalized successful response. Empty collections, malformed JSON, duplicate members, and nonresult or failure outcomes cannot advance the phase.

The controlled transport entry point is `send` in private `acquire.py`. Later installed and browser verification must route the candidate's same provider send through this boundary, with the same database and exact armed tuple. Use the returned metadata and stored raw body for comparison with the native result. A second provider call for comparison would consume a separate approved slot. The integration itself is due in the later candidate tasks.

The private verification and live-ledger directories were mode `0700`, and the ledger database was mode `0600`. Git ignored the raw storage. The readiness command reported no key in its environment. A presence-only check found a nonempty repository configuration assignment. No live secret was supplied to the rehearsal, browser, or acquisition CLI.
