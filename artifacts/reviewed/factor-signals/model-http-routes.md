# Authenticated model HTTP routes

Foundation task 8.1 packages a private ASGI entry point in the existing QOpenBB data runtime. Its factory is `qopenbb_data.modeling.service.bootstrap:create_app`. An internal listener serves discovery, evaluation, saved runs and individual outputs at `/modeling/v1`. The general data listener continues to serve its existing datasets. The public Workspace bridge and browser journeys have separate acceptance tasks.

The bridge contract uses a short-lived HS256 bearer assertion with an allowlisted key ID, the token type `qfm-identity`, issuer `qopenbb-workspace`, audience `qfm` and the authenticated user as subject. Configure the required `QFM_IDENTITY_CURRENT_KID` and `QFM_IDENTITY_CURRENT_SECRET` and optionally their `PREVIOUS` counterparts for rotation. Provision random keys with at least 256 bits of entropy. The service takes the UTF-8 secret bytes as provisioned. A missing or invalid key ring fails closed. The data origin and run directory can be set with `QOPENBB_MODEL_DATA_ORIGIN` and `QOPENBB_MODEL_RUN_DIR`.

A private loopback Uvicorn process exercised the packaged factory with a temporary key ring. A signed owner reopened a run created by the bounded calculation service and read its verified output. An unsigned caller received 401 and a different signed owner received 404. The production registry is empty until the later factor-registration task. Tests with an installed fixture exercised HTTP evaluation and compared saved verified, unverified and withheld values with their corresponding output projections. The suite uses offline data.

The HTTP adapter admits one evaluation by default and counts streamed request bytes against a 2 MiB limit. A body deadline also covers requests without a Content-Length. Errors carry a safe category, correlation ID and retryability. Once storage may have committed, the response identifies the original private run and disables automatic retry. A confirmed result remains available if the deadline races its response. The owner can reopen the original ID without calculating again.

The concrete file store receives the calculation worker's serialized run through a bounded pipe. Its supervised storage worker validates the run, publishes it atomically and verifies the owner-scoped readback. A cancelled worker is reaped. On filesystems that require named staging, an interruption can leave a private pending file outside the run lookup namespace. The portable test lock matches the service lock for PyJWT 2.15.1, FastAPI 0.143.0, Uvicorn 0.54.0 and Starlette 1.8.0, including wheel hashes.

Independent review approved the authenticated listener and publication handling against base bb31767. The review exercised 100 focused cases. The final Ubuntu portable gate passed 1,402 tests with 12 skipped and one deselected. All 836 inventory files passed the complexity check. The synchronized publication deadline regression also passed separately.
