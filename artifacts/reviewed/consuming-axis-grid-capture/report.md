# Use axis stroke and effective grid style width

The original dark grouped-column chart uses `line.stroke = #c1c1c2` for both axes. Its grid lines use `#515153`. Unequal-width experiments show that rendered grid width follows the effective `gridLine.style[].strokeWidth`. The attempted grid-style `strokeOpacity` field is unsupported: the original reports an unknown option and omits it from processed styles.
