# Preserve close/reopen state and distinguish theme resets from family navigation

The original keeps the active editor tab, expanded Vertical Axis group and scroll offset through dock-close and external reopen. Reopen focuses the active tab header rather than the previously focused field. The direct dark/light shortcut keeps chart and dock owners, but rebuilds Customize field groups collapsed and drops field focus. The captured Customize -> Chart -> family thumbnail -> Customize journey also returns collapsed groups while keeping those outer owners; it does not isolate the family change from the tab detour. Returning to the table restores widths and clears selection. Chart reentry creates a new chart/editor, opens the stored settings panel on the default Chart tab and starts its scroll at zero.

These are bounded original observations from 2026-10-17, not candidate acceptance. ## Preserve evidence limits

Every screenshot has matching state JSON. The run saved 36 checkpoints and used actual page mouse/keyboard/accessible UI actions. Named read-only GridApi/chart/getWidget references supplied finite state; no action used an API substitute. The controller approved the second bounded WidgetProvider acquisition chain and one real drag after source inspection explained the failed prerequisites. [a1 diagnosis](attempt-a1-diagnosis.md), [a2 diagnosis](attempt-a2-diagnosis.md) and [a3 diagnosis](attempt-a3-diagnosis.md) preserve those distinctions. The original click handler explains selection clearing; CSS explains hover-only resize handles. Failed scripts and cleanup receipts remain unchanged.

The original tab elements expose no `aria-selected` attribute: all captured values are null. The selected-tab claims above use the captured active tab focus, visible group/control content and visually inspected blue tab indicator in screenshots. The harness did not capture tab CSS classes, so it does not provide a machine-readable selected-tab flag. An absent flag is not treated as false or silently filled with the action's intended tab. Group expansion has actual `aria-expanded` values and node identities. After direct theme changes and after the recorded family navigation sequence, there is no overflowing Customize scroll owner; this establishes collapsed visible state, not the value of an inaccessible dormant scroll offset.

Finite projection omitted functions and non-plain AG row-node objects with explicit paths. No path/depth/array budget overflow occurred. The maximum omission count was 46, below the stored list cap of 64, so the verifier audits every omission reason in these checkpoints. Financial scalar values and category wrappers were retained. Model `chartOptions` includes only common/bar/line branches admitted by the plan; root chartOptions presence was recorded separately and remained absent. It does not prove arbitrary inactive-family leaves, callback behavior, broader saved option composition, or persistence. Body fallback focus labels include bounded synthetic app text; they are not semantic accessible-name claims.

The harness used 10-second stage deadlines for proxy update, animation inactivity and layout settlement, with a separate 30-second overall case deadline. This is a more granular implementation of the planned settlement bound; it does not establish a single combined 10-second wait. Observed cases all completed in less than three seconds. Cancellation stops subsequent actions and closes the owned browser; overall runner and cleanup watchdogs remain bounded. Scripts contain no dependency installation, image pull, build, owner browser attachment or provider call.

Read-only chart event identities were captured; outgoing dashboard payloads were not captured, because actual latest root/model state already answers these navigation questions. This run cannot establish backend saving, dashboard reopen, refresh/restart, editor write scheduling, export readiness, tooltip contracts, additional families or light/dark pixel parity against the candidate. Production code, breadth/spec status and activation guards were unchanged.
