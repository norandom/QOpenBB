## Proposed A2 contract using the frozen interface

Use the accepted `CaptureDisplayedChart = (input: GridCaptureInput) => SessionResult<ResolvedSnapshotInput>` without adding fields or a second result envelope. The following preconditions admit a narrow implementation; a caller that cannot establish them must retain the unresolved journey as a parity obligation.

1. The caller has a live, ready client-side flat GridApi and has flushed pending column state. It excludes grouped, pivoted, transposed, remote/infinite and pinned-row journeys. Missing/not-ready/destroyed API yields `waiting`; unavailable readiness must not be interpreted as an empty successful chart.
2. The caller validates the captured `stamp` against current session state using the accepted session helper before capture and before consuming its result. `GridCaptureInput` contains one captured stamp, not a current-session comparator; A2 cannot independently discover a later address/revision. Capture is synchronous, with no provider request, timer or state write.
3. `range` is already resolved by accepted A1 precedence against the current visible/generated IDs. `range.columnIds` is unique, ordered and matches the current grid. Hiding a selected column requires range re-resolution; A2 does not silently repair stored JSON or select a replacement series.
4. `categoryColumnId` names exactly one selected grid column with a category descriptor. All other selected columns have explicit numeric descriptors. Labels, units and scale come from the supplied descriptors, never headers, values, locale strings or AG inference. The initial admitted fixture uses `period` plus homogeneous USD-million numeric series.
5. Both row bounds absent means all displayed ordinary observations. A bounded range supplies ordered, nonnegative integer endpoints within the displayed count; endpoints are inclusive. This run proves 1..3. Reversed, partial, negative, fractional, stale out-of-count and pinned bounds require explicit diagnostics or separate contract evidence, not guessed normalization.

For an admitted input, A2 reads `getDisplayedRowCount()` and `getDisplayedRowAtIndex(i)` in ascending displayed index order within the resolved bounds. It requires each collected node to exist, have `displayed=true`, `group=false`, and a unique nonempty string `node.id`. It preserves that ID as the snapshot row ID; it never keys rows by category label or chart wrapper ID, and never invents an index-based fallback. Encountering a non-flat node is an unresolved source-mode mismatch, not permission to omit financially relevant aggregate data.

Read category and numeric observations through `api.getCellValue({rowNode, colKey, useFormatter:false})`. For the admitted ordinary scalar fixture, this equals provider data; the separate getter experiment proves why direct `node.data[field]` is not a universal replacement. Preserve finite zero/negative/fractional numbers and explicit null. Do not parse formatter strings, rendered DOM text, `-`, percent signs, separators or currency symbols. This run does not settle missing/undefined, nonfinite, date/object categories or object-valued numeric cells; retain these as named diagnostic/test cases before broadening the admitted contract.

Construct `ResolvedSnapshotInput` with `stateAddress=input.stamp.address.stateAddress`, `dataRevision=input.stamp.dataRevision`, `sourceMode="flat"`, ordered `selectedColumnIds=input.range.columnIds`, supplied `categoryColumnId` and descriptors, and collected row IDs/categories/numeric values. Preserve `input.originalModel` and `input.range.originalRange` as JSON provenance in `originalModel` and `selectedRange`; do not replace the original range with formatted chart output. Use the accepted `validateSnapshot` to validate and copy the result, preserving its precise path diagnostics. A ready envelope returns the same captured stamp and the validated value; invalid/malformed input and unsupported original semantics remain distinct `invalid`/`unresolved` outcomes under the accepted type.

The resulting ordinary bounded snapshot must contain rows with node IDs `4,0,3`, categories `2024-Q4,2024-Q1,2024-Q3`, numeric order `operatingIncome,revenue`, and exact arrays `[30,20,null]` / `[140,100,75.25]`. It must retain the synthetic source's explicit units and scale without numerical rescaling. `chartRange.ts` owns column precedence/intersection; A2 owns observation capture. Session helpers own stale-state validation; the mapper owns financial-unit compatibility and rendering.

## Separate joins and disproof conditions

Numeric-only runtime behavior is now observed, but the frozen snapshot requires the category to be selected and associated with a category descriptor. The generated `AG-GRID-DEFAULT-CATEGORY` is absent from the actual grid and original range. Its descriptor, identity, selected-range provenance and values therefore require an explicit caller-resolution design before admission. A2 must not manufacture a grid column or rewrite the frozen interface to make the case appear supported.

The two-category fixture resolves to period, despite a region-first fixture range. There is no captured `createRangeChart` input or Set Up category edit in this lane, so the normalization boundary remains unknown. Neither "first selected category wins" nor "first displayed category always wins" is established. Additional category-order permutations and actual category changes remain blocked until their model/input/output relationship is captured. This does not block an A2 caller supplying the already resolved explicit period category for the admitted fixture.

Remaining cases include missing cells, nonfinite/getter errors, zero-row/empty-filter behavior, refresh identity, pinned rows, group/aggregate/pivot/transpose/remote pages, hide-after-chart, category changes, tool-panel series reorder and persistence across save/reopen/restart. Source-only detached extraction rules must not be imported into this integrated adapter. This lane does not claim formatter callback invocation, export, settings completeness, theme parity or candidate behavior.

Disproof conditions for the bounded A2 proposal are: capturing raw-array instead of displayed order, exclusive end bounds, changing zero/null meaning, conflating duplicate labels, parsing formatted values, reversing selected numeric series, or losing original range/model provenance. A proposed implementation must fail independently specified assertions for any such change.
