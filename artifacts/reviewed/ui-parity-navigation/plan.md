## Feasibility and stopping rules

The existing completed harness proves these local tools and original image were usable for finite chart controls; it does not prove this navigation capture has run. Required UI actions have original source or prior locator evidence. Runtime discovery is limited to exact Grouped Column label, table resize handles, panel scroll owner, and finite getter acquisition. If any is unavailable, preserve the actual DOM/state and report that case unresolved; do not use a private API setter as a substitute or broaden the runtime search indefinitely.

Assertion failures are limited to identity/isolation/cleanup, a missing intended UI action, inability to establish the stated discriminator, incorrect selected family/theme after the requested action, changed synthetic source data, or a mismatch with a specifically proven source contract that remains visible at its deadline. Unknown tab/group/focus/scroll/selection reset or retention produces a finding, not an automatic failure. Source/runtime discrepancies are recorded with before/after evidence and remain unresolved until explained. Record skipped/dependent cases as unobserved.
