## Data and numerical rules

Consume setup output once, in row and assignment order. Reject duplicate row IDs, duplicate/unknown assignments, malformed values and arithmetic overflow through the existing invalid translation envelope. Null/undefined/nonfinite observations are absent. Retain raw value, row ID, row index, category label and column ID separately from geometric endpoints. Duplicate category labels remain distinct. Series identity/name is column ID; palette index remains assignment index, including hidden series.

Filter hidden series before totals, extents and group slots. Keep their legend entries with empty marks. For each row compute positive total P and negative total N independently. Grouped endpoints are [0,v]; stacked endpoints use prior signed cumulative total and that total plus v. Normalized endpoints use the same signed accumulation after multiplying each value by 100/max(P,abs(N)). If that denominator is zero, emit no normalized marks for the row. A missing observation contributes nothing and does not terminate iteration. Negative zero is retained as raw negative zero and follows the original negative branch. Non-normalized zero retains a zero-length mark; missing never becomes zero. Labels/tooltips format raw post-setup values, using count display when applicable.

Include zero in the domain; grouped extent includes individual visible values, stacked/normalized extent includes signed cumulative endpoints. Empty/all-hidden inputs have [0,0] and no marks. Category identity and slots remain stable when values are missing; visible group count changes when a series is hidden.

Column radius maps linearly: r(v)=H+(R-H)*(v-d0)/(d1-d0). For d0=d1 use the midpoint (H+R)/2, matching continuous-scale zero conversion; no invented normalized mark. Use the existing linear density/nice/tick helpers for radius, with numerical-axis font and available radial span. Keep domain and tick arrays distinct.

Bar full-circle domain: ordinary linear nicening with target 5, minimum 0, maximum Infinity; select its 1/2/5/10 step s, extend the interval count upward to 2^ceil(log2((b-a)/s)), retaining the nice start. Final stop is ceil(a/s+count)*s for s>=1, otherwise ceil((a+count*s)/s)*s. Generate ticks separately at target 8; do not use the last visible label as maximum. Degenerate domain stays [0,0]. Map theta(v)=-pi/2+2*pi*clamp((v-d0)/(d1-d0),0,1); degenerate conversion is midpoint. Swap negative endpoints to produce increasing angular sector bounds. Preserve an unwrapped full turn rather than reducing both endpoints modulo 2*pi.

Required original-axis fixtures: positive grouped [0,20], stacked [0,40], normalized [0,160]; mixed grouped [-10,30], stacked [-10,70], normalized [-50,150]; negative-only [-20,0]; zero [0,0]. Positive normalized 100 spans 225 degrees. Original raw ticks include the domain endpoint; omit its angular label when it duplicates the first position. Saved interval/min/max/reverse/partial-angle options are not represented by the frozen public style and are not newly promised by RC1.

## Bands and Column boundary

Use the source BandScale arithmetic, without rounding: for range [a,b], n bands, inner padding p and outer padding q, step=(b-a)/max(1,n-p+2q), width=step*(1-p), inset=a+((b-a)-step*(n-p))/2. For n=1 force p=0 and step=(b-a)*(1-2q). Band origin is inset+i*step, clamped to range. Empty band sets produce no marks.

Column category scale is [top,top+2*pi], zero scale padding, giving category ray top+i*2*pi/n. Category `paddingInner` reduces the available group span to (2*pi/n)*(1-paddingInner). Visible grouped series split this centered span using the band rule and `groupPaddingInner`; stacked/normalized use one group. Group outer padding is zero. Ordinary start/end are the category ray plus group origin and bandwidth. Exactly one source row instead sets start=-pi/2,end=3*pi/2 for every series, preserving the original overlap rather than inventing grouped wedges.

Column width uses delta=positive modulo difference between start/end. For delta<1e-3, width=2*R*maxColumnWidthRatio. Otherwise padded span=delta*columnWidthRatio and width=max(1,min(2*R*maxColumnWidthRatio,floor(2*R*abs(sin(paddedSpan/2))))). Ratios default to .5. Full-circle endpoints normalize to the same angle, so the single-row case uses the near-zero rule and width R at defaults. Shape rotation is normalizeAngle360(startAngle+delta/2+pi/2), using the same modulo delta above, never the arithmetic midpoint of full-turn endpoints. Thus single-row painted orientation is top. Column label anchors deliberately follow the separate source formula labelAngle=startAngle+groupBandwidth/2, labelRadius=(startRadius+endRadius)/2; labelX=cos(labelAngle)*labelRadius and labelY=sin(labelAngle)*labelRadius. This retains the original one-row distinction between label placement and painted shape. Bar labels use labelAngle=startAngle+angleBetween(startAngle,endAngle)/2 with the positive-modulo delta, and midpoint radius. This label-only modulo rule preserves the original full-turn label position; sector geometry retains its unwrapped full turn. Emit these center-relative labelX/labelY values on every prepared mark; paint must not infer them from shape rotation.

Connect the baseline only when abs(startRadius-H)<1e-10 (or exact equality) AND asin(width/(2*startRadius)) is finite and <pi/6. This is the source rule, normally width<H. Snap that connected start to H before calling the helper, which requires exact equality. Do not connect an inward negative segment merely because its end reaches H. Pass directed radii, H, R, width and connection to the accepted helper; preserve split arcs. Zero paths remain open with fill none, stroke/dash/opacity intact. Skip marks when drawable radius/span or band width is zero; never call the bounded helper with invalid pixels or silently clamp its 1,000,000-pixel limit.

Bar category scale uses range [R,H], paddingInner=.2 and paddingOuter=.1 by default. For category i, base radius=R+H-categoryBandOrigin(i); first input row is innermost. Split abs(categoryBandwidth) into visible group bands with groupPaddingInner=.2, outer padding zero; one group forces inner padding zero. Mark inner=base+groupOrigin, outer=inner+groupBandwidth. Stacked/normalized share the category ring. The radial hole comes from radius-category (.2), whereas Column uses radius-number (.5). Never source the hole from Bar's angle-number UI projection.

## Viewport and paint boundary

The numerical lane owns one center/R/H calculation and all mark pixels and label anchors. Use existing caption, legend reservation and text measurement conventions; reserve actual category-axis and numerical-axis fonts independently. Start with the accepted polar layout convention (remaining rectangle centered; radius bounded by half its smaller dimension minus label room). This is a replacement layout choice, not proven identity with the original iterative circle fitting. Paint must not recompute radii, normalization, groups or domains. Angular anchors carry radians for the existing fixed/parallel/perpendicular orientation semantics; radial anchors carry no angle. Category labels use category formatter, numerical labels use numericAxisLabel, marks use raw display. All anchors are center-relative. The model also emits explicit axisStrokes (circle radius or line endpoints, tagged category/numerical) for every painted axis line; paint applies that axis style and center translation only. Label offsets must never be used to reconstruct an axis radius or ray. Default axis lines follow the source axis boundary: angular axis is the outer circle R; radial axis is the top ray from H to R. The numerical lane emits these primitives with the correct family tag (Column circle category/ray numerical; Bar circle numerical/ray category); grid lines remain off unless separately frozen.

Use family-local ECharts custom series for Column and explicit sector geometry for Bar when native automatic layout cannot consume exact rings/endpoints. Both use the existing host, native legend, tooltip, resize/export lifecycle. Empty/hidden series keep stable native legend identity. Colors, independent axis paint, opacity, labels and supplied palette strokes come from RC2; default stroke width stays zero. No routing edits or feature flags in RC1.

No lane owns radialAssignments, radialContracts, shape helper, Nightingale files or shared routing. Controller owns inventory and the serial join. Each changed production file must pass 400 physical lines, 300 logical units, 50/function with existing inventory-backed verification. Review actual paths before dispatch; stop affected lanes for any interface change.
