# Original Color and Shadow behavior, nine bounded cases

The original dark groupedColumn editor accepts color-string alpha and renders Series Shadow. The tested Shadow tuple survives disable/enable, including all eight rendered bar rectangles. Preserve alpha inside the color string and represent Shadow as its own retained style tuple before consuming these findings in a renderer contract. Candidate rendering and persistence remain untested.

Opening a picker can itself mutate options. First opens emit normalized `rgb(193, 193, 194)`, `rgb(81, 81, 83)` and `rgba(0, 0, 0, 0.502)` for axis, grid and Shadow respectively. The source strings are equivalent at the displayed precision, but their model presence/representation changes. The later axis reopen emits nothing. Preserve these observed events when designing edit transactions; opening a picker is not reliably a read-only operation.

Axis writes appear at `bar.axes.category.bottom/top.line.stroke`. Grid writes appear at `bar.axes.number.left/right.gridLine.style[0].stroke`, retaining the observed first style's `strokeWidth: 1` and `lineDash: []`. This baseline has one grid style; it does not establish multiple-style retention or generic-versus-position precedence. Color-string alpha does not create an independent grid `strokeOpacity` or `opacity` member; both remain absent.

The Color wrapper is a focusable DIV with no explicit role, labelled through `aria-labelledby`. The popup is measured at 188 x 248 CSS pixels. Its spectrum, hue slider and alpha slider are focusable DIVs with no slider role or accessible label in the retained DOM projection. Three Tab presses move through hue, alpha and text; the text input also has no accessible name. These observations describe the original accessibility gap. They do not justify copying that gap into future controls. Wrapper display text and wrapper swatch CSS are visible in screenshots but were not projected as standalone scalar fields; popup text values and recent-swatch CSS colors are retained.

Blur's range input is 0..20 with step 1; its paired number input has step `any`. X/Y offset ranges are -10..10 with step 1; paired numbers again use `any`. Those attributes and these selected accepted values do not establish every permitted saved numeric value.

## Raster and bounds

[Raster measurements](attempt-20261017-r3-a2/raster-measurements.json) use lossless PNG bytes from the original screenshot. Four fixed regions per case are derived from recorded chart/plot and actual first-bar geometry. Each region is at most 128 x 128; outside-edge halo sampling extends 20 CSS pixels, with plot clipping explicitly recorded. Region images are derivatives of the same 24 viewport checkpoints, not additional browser captures. Exact RGB differences are counts for this experiment, without a general tolerance claim.

The axis-color action changes 96 pixels in the bottom-line region and zero in the grid region. The grid hex8 action changes 67 grid-region pixels. Enabling default Shadow changes 788 halo-region pixels. Shadow color, blur, X offset and Y offset change 788, 2376, 2484 and 1453 halo-region pixels respectively. C09 off and on each change 1770 pixels in the same region. All sampled bar-interior regions remain byte-identical across checkpoints; C09 restoration equals C08's halo crop exactly. Shadow can cross the line/grid sampling regions, so their later pixel changes are not attributed to axis/grid option changes.

The run used 51 UI API actions and 24 screenshot checkpoints. The collector's raw summary counter records 13 actions explicitly flagged as potentially changing. Its runtime guard did not count picker opens prospectively. Conservative offline accounting includes all four opens, for **17 <= 20**, because the event ledger proves that three opens changed options. The raw counter is retained rather than rewritten. There are 15 events, occupying 413374 bytes, and the raw action ledger occupies 51102 bytes; each is below 2 MiB. The [verification](attempt-20261017-r3-a2/verification.json) checks the conservative count, exact three-arrow sequence, all checkpoint sizes, nonempty `parentNode` ancestry, scene cardinality, color-channel isolation and Shadow retention. [Retained-byte accounting](attempt-20261017-r3-a2/retained-bytes.json) measures files on disk, with snapshot totals separate; rewrites do not accumulate imaginary output bytes.

Processed/live projections and model/events are retained separately. No existing documented finite generated/combined-theme seam was available to this collector, so that layer is explicitly unavailable. Baseline absent model leaves retain their absence; observed processed/live Shadow defaults are not substituted into them. The collector reads actual `datumSelection` rects and follows `parentNode`, recording inherited visibility/opacity and each own-member distinction within the eight-parent bound.
