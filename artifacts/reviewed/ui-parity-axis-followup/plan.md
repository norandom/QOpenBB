## Treat the I/O change as an offline hypothesis

The original writer scans all retained files on every write; saveEvents also rewrites unchanged chunks. [io.mjs](harness/io.mjs) scans actual disk once when each process initializes, then updates owned byte/file inventory prospectively, including overwrites and write failures that leave partial bytes. A failed write refreshes that target's actual retained size and propagates failure. Initial private/log/state exclusions match the original policy; writers cannot exploit those exclusions to create uncounted outputs. Untracked public additions, changes or removals fail final reconciliation. The writer rejects escaping paths and symlinks. The controller must provide an exclusively owned fresh run directory; concurrent external writers are prohibited.

PNG screenshots continue through the buffer writer, so their actual bytes are accounted before persistence. A reserved external-PNG interface is tested for any future direct path writer: reserve bounded prospective bytes, perform the external write, and finish in finally even after failure; unresolved reservations stop reconciliation. Shell status receipts now use the same writer. The wrapper writes provisional run-status=1 before finalization. Only a successful finalizer replaces it with the incoming result after checking actual JSON/PNG sizes and all retained files after cleanup/status receipts. Oversized or overflowed finalization therefore retains a nonzero status. Separate lifecycle processes each initialize from actual disk; they do not share stale in-memory inventories.

[events.mjs](harness/events.mjs) preserves the same compact serialized chunk/index schema. It writes only changed chunks/index, rejects shortened/changed prefixes and sequence gaps, and keeps the last successfully captured event prefix. On a closed page, finalization commits that prefix to the global event counter rather than replacing it with zero. Events after the last successful page read are explicitly unresolved; this cannot recover unseen browser events. The closed-page source path and prefix append/retry behavior are covered offline; browser integration remains unrun.
